# Chill PDF

Editor de PDF 100 % frontend (Next.js App Router + TS + Tailwind v4 + shadcn/ui, pdfjs-dist, pdf-lib, zustand + zundo, dnd-kit, react-rnd).

- Especificación completa y plan por fases: `docs/ai/README.md` (empieza ahí).
- Progreso actual: `docs/ai/PROGRESO.md`.
- UI en español; código en inglés.
- Sin backend, sin tests. Verificación = `npm run build` + `npm run lint` + prueba manual con `npm run dev`.
- Colores siempre vía tokens CSS (`bg-primary`, `bg-accent`…), nunca colores fijos de Tailwind.
